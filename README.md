# MyNewAI — AI สำหรับ OpenTTD

AI เขียนด้วย Squirrel ที่สร้างเส้นทางรถเมล์ระหว่างเมืองใหญ่ให้อัตโนมัติ
เริ่มจากตามบทเรียนของ [OpenTTD Wiki](http://wiki.openttd.org/) แล้วพัฒนาต่อเอง

## ข้อมูล
| หัวข้อ | ค่า |
|---|---|
| ชื่อ | MyNewAI (`MFAI`) |
| ผู้เขียน | Arismonx |
| เวอร์ชัน OpenTTD ที่ทดสอบ | 15.3 |
| API version | 12 (ตามที่ประกาศใน `info.nut`) |
| วันที่เริ่ม | 2026-09-15 |

## สิ่งที่ AI ทำได้ตอนนี้
1. กู้เงินเต็มวงเงิน
2. เลือก 5 เมืองที่ประชากรมากที่สุด
3. หาที่ว่างใกล้ใจกลางเมืองสำหรับสถานี + อู่ แล้วสร้าง
4. หาเส้นทางถนนด้วย A* และปูถนน (รวมสะพานและอุโมงค์)
5. ซื้อรถเมล์ 1 คัน สั่งวิ่งสลับสองสถานี

| `docs.md` | เอกสารอธิบายการทำงาน ปัญหาที่เจอ และแผนพัฒนา |

## วิธีใช้
1. วางโฟลเดอร์นี้ไว้ใน `ai/` ของ OpenTTD (เช่น `openttd-15.3-.../ai/MyNewAI`)
2. เปิดเกม → AI/Game Script Settings → เลือก MyNewAI
3. เริ่มเกมแล้วดู log ในหน้าต่าง AI Debug
